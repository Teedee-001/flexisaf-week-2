# FlexiSAF Internship — Week 2

## Topic

Python Syntax, Variables, Data Types and Input/Output.

## Projects

1. **Profile Card:** Collects and displays user information.
2. **Age Calculator:** Estimates age using the birth year.
3. **Unit Converter:** Converts kilometres to miles.
4. **Receipt Total:** Calculates the total cost of purchased items.
5. **Simple Interest Calculator:** Calculates simple interest and the final amount.

## Concepts Practised

- Variables and naming
- Strings, integers and floating-point numbers
- User input and printed output
- Type conversion using int() and float()
- Arithmetic operators
- Comments and f-strings
- Basic debugging

## How to Run

Open a terminal in this folder and run any program:

python profile_card.py
python age_calculator.py
python unit_converter.py
python receipt_total.py
python simple_interest.py
